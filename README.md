# Mobile-Android-Agent

Standalone component of the Codestra authorized mobile-device management platform.

## Security boundary
This software is for devices owned by, or explicitly enrolled with authorization from, the operator. It does not bypass OS security, banking verification, authentication, application sandboxes, or third-party security controls.

## Responsibilities
- Android Enterprise / Device Owner client boundary
- Enrollment and policy application
- Device health and command acknowledgement
- No credential or verification bypass
